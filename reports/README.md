# Reports

Place the final write-up here as `final_report.pdf`. It should cover:

1. Introduction & problem statement
2. Related work
3. Dataset & exploratory analysis
4. Methodology (preprocessing, the 3 models, evaluation protocol)
5. Results & discussion (referencing tables/plots in `../results/`)
6. Conclusion & future work
7. References (compiled from [`references.bib`](references.bib), IEEE style)

`final_report.pdf` is not included in this scaffold — generate it once the
experiments in `main.py` / the notebooks have been run and results are
available to report on.
